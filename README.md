# Great British Railways Careers (Roblox) — Branded Build

This is a Next.js + Tailwind CSS + Supabase-ready recruitment website themed around the provided Great British Railways logo.

## Included
- GBR-branded homepage
- Searchable vacancy listings
- Individual job pages
- Demo jobs for immediate use
- Supabase schema + seed files
- Uploaded GBR logo integrated into the header, hero and footer

## Run locally on Windows PowerShell

```powershell
cd first-rail-rebuilt
npm.cmd install --include=optional
npm.cmd run dev
```

Then open the local address shown in the terminal, usually http://localhost:3000.

## Notes
- This is an unofficial Roblox roleplay recruitment site.
- Jobs are fictional and for roleplay/community use.
- Roblox login, applications and HR dashboard are not yet included in this build.
